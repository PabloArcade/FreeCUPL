FreeCUPL changes

2.2.0  2026-11-18

New program for Windows: freecuplw.exe, an editor and front end for
freecupl and freecsim (docs/USERGUIDE.txt, section 8).  Editor with
tabs, undo, find and replace and syntax colouring; Compile and Simulate
commands with an options dialog for the flags; message pane where a
double click goes to the line of an error or opens an output file;
read-only viewers for the .jed, .doc, .lst and .so files; searchable
device list that inserts the Device statement; the user guide under
Help.  It runs freecupl.exe and freecsim.exe from its own directory, so
the results are those of the command line.  Settings are kept in
freecuplw.ini next to the program; the registry is not used.  Windows
XP SP3 and later, 32-bit, written against the Win32 API.  Linux and
macOS keep the command line; freecuplw.exe also runs there under Wine.

The compiler and the simulator are unchanged; only the version in the
file headers differs.  The device list of the user guide is now
section 9.

tools/check_xp.sh accepts executables of the Windows GUI subsystem
with the imports on tools/xp_allowlist_gui.txt.

2.1.0  2026-11-17

New device: ATV5000 (v5000).  Two registers and three sum terms in
every I/O cell, buried cells, universal and regional product terms,
clock pin or product-term clock, .CE, .LQ and .IOL; simulated by
freecsim.  No device was available: the simulation model of this part
is not verified, and freecsim says so.

New devices: GAL26CV12 (g26cv12) and GAL20XV10 (g20xv10, g20xv10i,
g20xv10f and the 28-pin g20xv10lcc, g20xv10ilcc, g20xv10flcc).

New 28-pin mnemonics: GAL20RA10 (g20ra10lcc), PAL20RA10 (p20ra10lcc,
p20ra10mlcc, p20ra10slcc), PAL22CV10 (p22cv10lcc), PAL20C1 (p20c1lcc,
p20c1mlcc), PAL10016RD4 and RD8 (p1016rd4lcc, p1016rd8lcc),
PAL10016ET6 (p1016et6lcc), PLSI1016LD4 and PAL10016LD8 (p1016ld4lcc,
p1016ld8lcc).  327 mnemonics are supported; docs/USERGUIDE.txt,
section 6, lists the 93 that are not, with the reasons.

WinCUPL bugs B034 to B040 (docs/BUGS.txt), corrected by default and
reproduced by -compat-refdefect:
  B034 to B036, B038  ATV5000 compiler: a register of another quadrant
        read through the reader's regional bus (now rejected), sum term
        C cut off on the wrong cell, a register without .CK and .CE
        never clocked (the clock term is now written true, after the
        data sheet; not verified on a device), .IOL of pin 25.
  B037  every registered part: a combinational equation next to a .D
        equation complemented at its root was ORed into the register.
        FreeCUPL rejected such designs in both modes; with
        -compat-refdefect it now accepts what WinCUPL accepts.
  B039, B040  ATV5000 simulator: input values taken as pin levels;
        outputs read complemented by other equations.

-compat-refdefect, closer to WinCUPL:
  -kb also complements registers with reset or preset in use (22V10
  types, ATV750, RA parts);
  PAL16C1 and PAL20C1 with an equation on both outputs are accepted or
  rejected by WinCUPL's rule;
  PAL10016ET6: -kb follows B001 as on the other parts.

Device descriptions: rows of different widths (vrows), lines+
(docs/DEVFMT.txt).  The absolute file has a new record, FBINV
(docs/SIMFMT.txt).

2.0.0  2026-11-17

The WinCUPL 5.0a bugs B001 to B033 (docs/BUGS.txt) are corrected by
default.  The warning still names the bug where it affects a design.
-compat-refdefect reproduces WinCUPL 5.0a exactly, bugs included, as
1.0.0 did by default; -fix is accepted and does nothing.  Building with
make FIX_DEFAULT=0 gives the 1.0.0 default.

make check runs every test case in both modes.

The Windows XP check (tools/check_xp.sh) reads the import table of
newer binutils and has a self-test.

1.0.0  2026-11-16

First public release.

freecupl: CUPL compiler with the command line of WinCUPL 5.0a.  Full
CUPL language and preprocessor, minimisation -m0 to -m4, -kb, JEDEC,
documentation, listing, macro expansion and absolute files.  For every
design WinCUPL accepts, the JEDEC file makes the device behave as
WinCUPL's does.

freecsim: CSIM-compatible simulator.  .si test vectors, .so listing,
.wo waveform file, test vectors in the JEDEC file; also run by
freecupl -s.

307 device mnemonics (docs/USERGUIDE.txt, section 8).

The WinCUPL 5.0a bugs B001 to B033 (docs/BUGS.txt) are reproduced by
default with a warning; -fix gives the corrected result.

Helper tools jedsim, equiv and jedtool.

Builds for Windows XP SP3 and later, Linux and macOS from one C99
source.  SOURCE_DATE_EPOCH sets the date in output headers.  make check
runs the test suite.

The programs were developed under the working names dcupl and dcsim.
